# Provenance and notices

## Pegline implementation

Pegline is an independently named Windows implementation authored for this request. Its C# source follows the reviewed Tendedero behavior, selected numerical layout/animation constants, and Windows integration ideas observed in Cordel. It is not an upstream Tendedero release and is not endorsed by either reference project's author.

The code was written from source available in the connected GitHub review. Container download failure prevented reproducing upstream source archives locally. No upstream binary is embedded or redistributed. The included icon was newly constructed for Pegline; sounds are synthesized in `src/Sounds.cs` rather than copied from macOS.

No third-party code package is required by the Windows build. WPF, Windows Forms, System.Drawing, the framework serializer, and the Visual Basic file-operation helper are Microsoft .NET Framework assemblies supplied by the target platform, not vendored source or binary packages. Windows APIs and shell services remain subject to the target platform's terms. Font family names are references to fonts on the user's machine; no font files are bundled.
